# Optional live-demo evidence

Run `bash scripts/demo.sh --capture` to create a timestamped `session-*` directory containing genuine terminal output. Session directories are ignored by default.

Before intentionally committing a selected transcript:

1. confirm the date, machine role and command context;
2. remove unrelated personal paths or terminal content;
3. confirm it contains no passwords, tokens, private keys or private certificate material;
4. retain failures honestly rather than editing them into passes;
5. update `evidence/README.md` with what the artifact actually proves.
